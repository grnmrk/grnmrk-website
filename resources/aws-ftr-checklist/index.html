Top FTR Failure Reasons: What to Check Twice
Wildcard IAM permissions
Any iam:*, s3:*, or *:* in production policies will fail. Audit every role before submitting.
Hardcoded access keys
Long-term access keys embedded in code or stored on EC2 instances. Use IAM instance profiles instead.
No ACE opportunity on file
Required before FTR can be approved. Create and submit at least one ACE opportunity first.
Evidence without context
Screenshots that do not clearly prove what they are meant to show. Label everything and crop to the relevant section.
