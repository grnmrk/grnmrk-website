AWS Partner Funding Programs

AWS MAP Funding
Checklist

Everything required to qualify, apply, and get approved for Migration Acceleration Program funding, without the details that get submissions denied.

Program: Migration Acceleration Program (MAP)
Eligible: Select, Advanced & Premier Partners
Funding: Up to 25% of migration project value

AWS MAP is one of the highest-value funding programs available to AWS partners and one of the most commonly mishandled. Submissions fail not because the project is ineligible, but because of incomplete evidence, ACE prerequisites that were not met, or documentation that does not match what AWS expects.

This checklist walks through all four stages: partner eligibility, ACE opportunity setup, MAP assessment submission, and post-approval compliance. Work through it before you submit, not after you get rejected.

  • ACE opportunity setup requirements (must exist before MAP submission)

  • Post-approval compliance steps and milestone tracking

Most Common MAP Denial Reasons
No ACE opportunity on file
The most common failure. Partners apply before creating the ACE record in Partner Central.
Missing customer AWS account ID
Required on the ACE record. Applications without it are returned immediately.
Vague scope documentation
AWS needs to see what is being migrated, from what, to what, and when.
Project already completed
MAP cannot be applied retroactively. The application must precede or accompany the migration.
